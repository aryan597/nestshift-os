# Screenshots

Add your screenshots to this folder and reference them from the main README.

## Required images for maximum GitHub impact

| Filename | Description | Dimensions |
|---|---|---|
| `dashboard-hero.png` | Full dashboard view in dark mode, showing the main Overview page | 1200×600 |
| `brain-panel.png` | NARE Brain page with neuron activity charts and synapse stats | 800×500 |
| `energy-panel.png` | Energy page showing live cost, forecast chart, and savings | 800×500 |
| `safety-panel.png` | Safety monitor showing Pi-safe constraints and status | 800×500 |
| `demo-gif.gif` | Short looping GIF of the dashboard updating in real time | 800×450 |

## Tips

- Capture in dark mode (the default OrbitAI theme).
- Use a browser at 1440×900 or 1920×1080.
- For the GIF: show the Energy page updating as mock data changes, or the Brain page spike chart animating.
- Compress PNGs with a tool like Squoosh or ImageOptim before committing.

Once you add these images, update the `README.md` to uncomment the image references.
